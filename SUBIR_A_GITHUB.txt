HIMNARIO BIT YIK KI MAM DIOS - LISTO PARA GITHUB PAGES

1. Cree un repositorio publico en GitHub, por ejemplo: himnario
2. Descomprima este ZIP.
3. Suba DIRECTAMENTE al repositorio estos archivos y carpeta:
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - icons/
4. No suba el ZIP como unico archivo.
5. En GitHub entre a Settings > Pages.
6. Source: Deploy from a branch.
7. Branch: main. Folder: /(root). Presione Save.
8. Espere unos minutos y abra la direccion que GitHub Pages le muestre.
9. En Android abra la pagina con Chrome y use Instalar aplicacion. Tambien puede abrir el menu de tres barras de la app; si el navegador lo permite aparecera “Instalar app”.
10. En iPhone: Safari > Compartir > Agregar a pantalla de inicio.

La app queda disponible sin internet despues de que el navegador haya guardado los archivos offline.
