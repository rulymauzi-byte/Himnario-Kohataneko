HIMNARIO BIT YIK KI MAM DIOS — APP INSTALABLE

Esta versión funciona como aplicación web instalable (PWA) en Android y iPhone.
Una vez instalada y abierta al menos una vez, funciona sin internet.

PARA PUBLICARLA:
1. Suba todos los archivos de esta carpeta a un sitio HTTPS, por ejemplo GitHub Pages.
2. Abra la dirección publicada desde el celular.

ANDROID (Chrome):
- Toque el menú ⋮ y elija “Instalar aplicación” o “Agregar a pantalla principal”.
- Si aparece “Instalar app” en el menú ☰ del himnario, también puede usarlo.

IPHONE (Safari):
- Toque Compartir.
- Elija “Agregar a pantalla de inicio”.

IMPORTANTE:
- No borre manifest.webmanifest, service-worker.js ni la carpeta icons.
- El himnario está incluido dentro de index.html y no necesita internet para leer los himnos después de instalarlo.
